# Концепция v6: SORP Lead Centre

Для владельца SORP Group. Версия 6, 2026-09-09. Отличия от v5 — ответ на вердикт
`../research/13_owner_verdict_v5.md`: пять условий владельца внесены в §7 дословно, пометки исправлены. Пометки: ИЗМЕРЕНО (первоисточник открыт или вывод
скрипта в репо), НЕПРОВЕРЕНО (сниппет; домен закрыт — `docs/ops/network_policy.md`), ВЫБРАНО.
Числа §4 — вывод `calc.py` (`calc_output.txt`); суммы §6 — ручные, округлены вверх.

## 1. Проблема

Вы платите за входящий трафик (16 листингов Bayut, PF, dubizzle, агрегаторы, RU-лендинги —
ресерч 05 §4, сниппеты первоисточников). Запрос стоит AED 100–400 по рыночным CPL (НЕПРОВЕРЕНО).
Аудит HBR 2011 на 2241 компании: 23% запросов без ответа, среднее время 42 ч (ресерч 10 §1;
**НЕПРОВЕРЕНО — по сниппету, первоисточник закрыт**; единственный не-вендорский источник по теме).
Сколько теряет SORP — не знаем; §7 измеряет за неделю на ваших данных.

## 2. Что предлагаем

**Lead Centre** — один движок для каждого входящего запроса (форма, WhatsApp, Property Finder):
1. **Разбор**: что просят, юрисдикция, люди, срок, бюджет, язык.
2. **Приоритет** HIGH/MEDIUM/LOW по рубрике «адрес сейчас × событие × срочность», с причинами.
3. **Черновик ответа** RU/EN, 4–6 строк, диапазоны **только из вашего прайс-файла**. Отправляет
   человек. Всегда. Ни одно сообщение клиенту без нажатия менеджера — нарушение = стоп пилота.
4. **Авто-квитанция** — отдельная опция и отдельное решение владельца **после** пилота (§4, §7).
5. **Передача** в CRM одной кнопкой; «не согласен» с причиной → в набор тестов.

Продукт — пакет: регистрация + офис + визы + счёт + бухгалтерия. Выручка первого года: с офисом
в SORP BC ≈ AED 87k, без офиса ≈ AED 42k (ресерч 07 §1, РАСЧЁТ на ВЫБРАНО: офис 45k и сервисный сбор 6.5k — допущения). Маржа вклада — ВЫБРАНО 50%
(бухгалтерия и визы — часы людей); ваша цифра заменит нашу (§12.5).

**Почему входящие первыми, а не база 500+ компаний с лучшим ROI (ресерч 07 (c)):** база требует
ваших данных и договорных оснований, которых у кандидата нет; входящие можно показать на
синтетике за 3 дня. Это ограничение тестового, не приоритет продукта. В дорожной карте база — фаза 2.

## 3. Почему «черновик + человек»

Два RCT Alibaba (arXiv 2605.14830 — 647 операторов, 680 676 чатов; 2603.29888 — объём в ресерче
не приведён): автоответ снижает оценки клиентов, черновик оператору повышает скорость и оценки
(ресерч 10 §6; ИЗМЕРЕНО по abstract, полный текст PDF не разобран). Линтер, сверяющий каждое число
AED с прайс-файлом, и тест на мутацию цены — **критерий приёмки MVP** (кода в репо ещё нет),
прогоняются при владельце.

## 4. Экономика: инструмент, процесс и честный пессимизм

`ΔK = I·[(h′ − h) + k_ack·a]·(cf − cs)·c`, `V = ΔK·R`, порог `ΔK_be = T / (R·маржа)`.
- `h′` — доля запросов, отвеченных человеком ≤ 1 ч, **свойство графика**: A = 55% (09–18 +
  черновики), B = 75% (+ дежурный до 22:00). ВЫБРАНО, измеряется в пилоте.
- `a` — доля запросов, закрытых только авто-квитанцией (C: 15%); `k_ack = 0.3` (ВЫБРАНО) —
  квитанция даёт не больше трети эффекта человеческого ответа. В v4 она считалась как ответ —
  ошибка, исправлена.
- `T` по сценариям — §6. Порог считается **по марже**, не по выручке.

Вывод `calc.py` (консервативно I=150, h=40%, cf=25%, cs=12%, c=20%; пессимистично I=80, h=55%,
cf=18%, cs=13%, c=15%):

| | ΔK | V с офисом / порог | V без офиса / порог |
|---|---|---|---|
| Консервативно A | 0.585 | 50.9k / 0.069 ✓ | 24.6k / 0.143 ✓ |
| Консервативно B | 1.365 | 118.8k / 0.149 ✓ | 57.3k / 0.310 ✓ |
| Консервативно C | 1.540 | 134.0k / 0.152 ✓ | 64.7k / 0.314 ✓ |
| Пессимистично A | 0 | 0 / 0.069 ✗ | 0 / 0.143 ✗ |
| Пессимистично B | 0.120 | 10.4k / 0.149 ✗ | 5.0k / 0.310 ✗ |
| Пессимистично C | 0.147 | 12.8k / 0.152 ✗ | 6.2k / 0.314 ✗ |

Читать честно: **при пессимистичных входах проект не окупается ни в одном сценарии по марже.**
Пессимистичный A = 0 по конструкции: вход h = 55% равен h′_A — «пессимизм» здесь означает «у вас
уже 55% отвечают за час», то есть пессимизм про потребность, не про инструмент. Неделя 0 отвечает
на один вопрос: ваше h ближе к 40 или к 55.
Решение зависит от трёх ваших чисел — `I`, `h`, `cf − cs`. Их даёт неделя 0 пилота, а не
презентация. Если после недели 0 входы ближе к пессимистичным — мы сами предложим остановиться.

## 5. Строить или купить

Канал и CRM покупаем (WATI/respond.io $99–159, HubSpot Free), ядро строим: вендоры не кодируют
рубрику и не читают реестр; HubSpot Breeze $450–500/мес, русский в списке языков не упомянут
(ресерч 08, НЕПРОВЕРЕНО по ценам и языкам).

## 7. Пилот: условия, которые владелец подписывает (дословно из вердикта 13 §E)

1. **Данные не покидают SORP.** VPS в ОАЭ, NDA до первой выгрузки. В модель — псевдонимизированный
   текст: гражданство и число людей — да; имена, телефоны, паспорта, email — нет. **CRM пилота — на
   том же VPS (Postgres); HubSpot и любая облачная CRM — только отдельным письменным решением
   владельца** (у HubSpot нет региона в ОАЭ, ресерч 09 §3). На аккаунтах кандидата — только синтетика.
2. **Ни одного сообщения клиенту без нажатия менеджера; ни одной цифры AED не из `PRICELIST.yaml`
   владельца.** Нарушение — стоп в тот же день с записью в отчёт.
3. **Сценарий A, 4 недели, чередование дней с черновиками / без.** Три исхода (Р1):
   - «стоп» — доля без ответа в рабочие часы не упала на треть **или** черновики переписывают чаще,
     чем принимают;
   - «дальше» — решение по B/C и фазе 2 принимается отдельно;
   - «не смогли проверить» — в дни с черновиками набралось < 60 запросов → продление на 4 недели
     или стоп, но не B/C. Стоп-условие считается в штуках: `проверено N / без ответа M / принято K`.
4. **До старта в репо и прогнано при владельце:** `HANDOVER.md`, `PII_RULES.md` с негативным тестом
   (телефон в тексте → не попадает в промпт), линтер цен с тестом мутации; тексты §9 — **с визой
   юриста владельца**. Нет — пилот не стартует.
5. **Деньги и часы.** MVP — 0. Пилот — VPS ≈ 200 AED/мес, LLM ≈ 30 AED/мес и записанное число
   часов менеджеров (§6). По итогу — отчёт `проверено N / без ответа M / принято K` и три числа
   владельца `I`, `h`, `cf − cs` в файле, который остаётся у SORP.

**Неделя 0.** Выгрузка входящих за 3 месяца (WhatsApp Business экспорт — по чату вручную; почта;
форма; PF). Если CRM нет и чаты на личных телефонах — это первый результат и первый вопрос. По
каналам и разрезам (рабочие часы/вне; RU/EN): доля без ответа вообще, медиана и 90-й процентиль
первого ответа, конверсия в консультацию при ответе ≤ 1 ч и > 1 ч (`h`, `cf`, `cs`). Если конверсию
посчитать нельзя — пилот измеряет только скорость и долю без ответа, и это записывается.
Проверку Coexistence для номера ОАЭ делает владелец или BSP (домен Meta закрыт для кандидата).

**Недели 1–4.** Менеджер отвечает сам из WhatsApp как обычно, черновик видит в дашборде.
Метрики недели 0 плюс доля принятых черновиков без правок и disagree-rate по приоритету.
Стоимость часа дежурного (§12.2) нужна **до** пилота, иначе решение по B после него снова
упрётся в данные владельца.

## 8. Стек: демо и пилот — разные вещи

Демо (3 дня) — Vercel + Supabase на аккаунтах кандидата, только синтетика. Пилот — один VPS SORP,
`docker compose up`: Postgres (данные и CRM пилота), API, дашборд, n8n; данные хранятся **в ОАЭ**,
за границу уходит только псевдонимизированный текст запроса на инференс. До пилота в репо (сейчас — обещание, критерий приёмки §7.4): `HANDOVER.md` (что сломается
первым, логи, откат), `PRICELIST.yaml` (ваш), `NOTICE_ru.md`/`NOTICE_en.md`, `PII_RULES.md` с тестом.

## 9. Менеджеры и данные

- В пилоте (сценарий A) черновик живёт в дашборде, менеджер отвечает из WhatsApp как обычно.
  Доставка черновика в телефон дежурного (сценарий B) — через shared inbox BSP или уведомление
  в WhatsApp/Telegram менеджеру; Coexistence для ОАЭ **не проверен** (домен Meta закрыт) —
  проверяется в неделю 0. Это отдельное решение после пилота.
- Anthropic не обучается на данных; не хранит запросы по умолчанию **при Opus 5 / Sonnet 5 / Haiku 4.5**
  (Covered Models — Fable/Mythos — хранят 30 дней; смена модели требует перепроверки); DPA/SCC в
  условиях (ИЗМЕРЕНО).
- PDPL: регламентов нет; передача допустима при договорных гарантиях и уведомлении (НЕПРОВЕРЕНО по
  юрфирмам). Тексты — на визу юриста владельца до пилота:
  - *Форма (RU):* «Отправляя запрос, вы соглашаетесь на обработку указанных данных SORP Group для
    ответа на ваш запрос. Данные обрабатываются с помощью автоматизированных инструментов, в том
    числе за пределами ОАЭ, и хранятся до 24 месяцев. Подробнее — Политика конфиденциальности.»
  - *Первый ответ (RU):* «Черновик ответа подготовлен с помощью ИИ и проверен менеджером SORP.»
  - EN — по смыслу те же. 24 мес — ВЫБРАНО.

## 12. Вопросы владельцу (без них цифры остаются ВЫБРАНО)

1. Есть ли CRM (Bitrix24?); если нет — `cf/cs` в неделю 0 не измеримы, HubSpot Free становится первой CRM.
2. Стоимость часа дежурного до 22:00 и согласие менеджеров по трудовому договору.
3. Кто и за сколько часов выгрузит 3 месяца WhatsApp Business (по одному чату).
4. Доля запросов с Property Finder и есть ли у PF выгрузка/API (НЕПРОВЕРЕНО).
5. Маржа по бухгалтерии и визам — для порога по прибыли.
6. Есть ли вакансия в SORP BC и на какой срок; доля клиентов с полным пакетом.
7. Тексты §9 — на визу вашего юриста; кто владелец инструмента внутри SORP.
8. Отдельное письменное решение по облачной CRM (HubSpot) после пилота — или остаёмся на Postgres.

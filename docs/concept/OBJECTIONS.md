# Реестр возражений владельца SORP (цикл «ресерч → концепция → критика»)

Цель цикла (стоп-условие): владельцу нечего возразить, он готов обоснованно принять проект.
Статусы: `открыто` — ответа нет или он на вендорских цифрах; `частично` — есть ответ с оговорками;
`закрыто` — ответ с первоисточником или с решением в концепции, которое снимает возражение.
Правило: возражение закрывается только ссылкой на документ в репо, не словами в чате.

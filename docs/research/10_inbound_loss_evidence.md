## 5. Калькулятор
Входы: `I` запросов/мес; `h` доля до человека ≤1 ч сегодня; `cf`/`cs` доля консультаций при
быстром/медленном ответе; `c` закрытие из консультации; `R` выручка 1-го года (AED 87k, ВЫБРАНО);
`T` стоимость инструмента (AED 3–5k/мес); `h'` после внедрения (ВЫБРАНО 90%).
```
K0 = I·[h·cf + (1−h)·cs]·c
K1 = I·[h'·cf + (1−h')·cs]·c
ΔK = I·(h'−h)·(cf−cs)·c        V = ΔK·R        ΔK_be = T/R
Проверка: cf/cs ≤ 2 — консервативнее любого множителя §1.
```
**Консервативный** (I=150, h=40%, cf=25%, cs=12%, c=20%, h'=90%): K0 = 5.16, K1 = 7.11,
ΔK = 1.95 кл/мес → V ≈ AED 170k/мес; порог 5000/87 000 = 0.057 → запас ≈ 34×.
**Пессимистичный** (I=80, h=55%, cf=18%, cs=13%, c=15%, h'=85%): ΔK = 0.18 → V ≈ AED 15.7k/мес;
запас ≈ 3×. Даже при cf−cs = 2 п.п. (ΔK = 0.072) инструмент за 5k окупается.
Чувствительность: V линейна по (cf−cs) и (h'−h) — две константы, которые владелец не знает.

## 6. «Черновик + одобрение» vs полная автоматизация (arXiv, открыто напрямую)
- Alibaba RCT, 647 операторов, 680 676 чатов (arXiv 2605.14830): агент, отвечающий сам, сокращает
  чат, но **существенно снижает оценки клиентов**; вмешательство человека сохраняет качество.
- RCT там же (arXiv 2603.29888): ИИ, **предлагающий черновик оператору**, повышает скорость и
  рейтинги без роста повторных обращений.
- Scambaiting (arXiv 2509.08493): Human Acceptance Rate ~70% черновиков без правок; средняя
  правка 14.4 символа — ориентир для метрики принятия.
- Stanford/JAMA 2024: 162 клинициста, утилизация черновиков 20%. НЕПРОВЕРЕНО. Диапазон 20–70%
  по доменам — измерять свою.

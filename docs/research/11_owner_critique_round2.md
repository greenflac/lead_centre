## B. Возражения по весу
1. **Экономика считает эффект, который продукт не производит.** Черновик ускоряет набор, но не
   будит менеджера ночью (40% запросов 20–08, вендорское). V ≈ 170k/мес — цена дежурного, не
   инструмента. Убедит: h′ как функция графика; строка «авто-квитанция без цены в 24-часовом окне».
2. **«Не зависит от вакансии» — неправда в числах.** R = 87k включает 45k за офис. Без вакансии
   R ≈ 42k, порог удваивается, запас 3× → ~1.5×. Убедит: два R и доля клиентов с полным пакетом.
3. **Пилот измеряет не то.** «Время до ответа вдвое» упадёт только в рабочие часы; «принятие
   черновиков < 30%» — чужая граница. Убедит: разрезы (часы/вне, RU/EN), главная метрика —
   «без ответа вообще» (HBR 23%).
4. **Eval 30 запросов — синтетика, размеченная тем, кто делал.** κ на своих же примерах — согласие
   автора с собой. Убедит: 30 реальных обезличенных запросов, размеченных менеджером SORP.
5. **Ручной обзвон «найденных» — тот же телемаркетинг.** Список из Dubai Pulse → менеджер звонит/
   пишет без согласия → Res. 56/2024. Лицензия Dubai Pulse НЕПРОВЕРЕНА, а вкладка Discovered
   строится в день 1. Убедит: регламент контакта с юр. оценкой до того, как список у менеджера.
6. **Капекс скрыт, опекс не тот.** $37–92 — только LLM+хостинг; нет разово AED 15–60k, поддержки
   500–5000/мес, Meta с 01.10.2026, верификации 1–3 нед, лимита 250/сутки. T = 5k не объяснён.
   Убедит: таблица «разово / в месяц / кто платит».
7. **Стек противоречит сам себе.** «Один Docker Compose» vs Vercel + Supabase + n8n + cron
   keep-alive. Handover «нужен» = не написан. Убедит: один стек, счета SORP, лист «что сломается
   первым» до пилота.
8. **Прайс в ответах — не мой.** Демо-прайс, линтер режет фразы, не проверяет диапазон. Убедит:
   прайс — только файл владельца, линтер сверяет, тест на мутацию цены.
9. **Моё имя.** Notice, пометка «ИИ», срок 24 мес меняют сайт и тон; PDPL-часть НЕПРОВЕРЕНО.
   Убедит: формулировки RU/EN на согласование.

# GLEIF: источник для лидогенерации — схема и замеры 2026-09-09

`https://api.gleif.org/api/v1/lei-records` — глобальный реестр LEI. Без аутентификации,
JSON:API, фильтры и сортировка. Всё ниже ИЗМЕРЕНО запросами из этой среды.

## Объём по ОАЭ

| Срез | Записей |
|---|---|
| Юридический адрес в ОАЭ | **9 362** |
| Юрлицо активно (`entity.status=ACTIVE`) | 9 229 |
| Регистрация LEI действует (`registration.status=ISSUED`) | 5 294 |
| **Регистрация LEI просрочена (`LAPSED`)** | **3 937** |
| RETIRED / ANNULLED / PENDING_TRANSFER | 97 / 3 / 1 |

Новых юрлиц с LEI по ОАЭ появляется ≈20–25 в месяц (по 600 свежайшим записям:
65 создано за последние 90 дней).

## Поля, пригодные для скоринга

| Поле | Что даёт |
|---|---|
| `entity.legalName`, `otherNames` | название на арабском и английском |
| `entity.legalAddress.addressLines` | **адрес регистратора виден текстом** — «Meydan Grandstand, 6th floor», «Sharjah Publishing City Free Zone» и т.п., то есть флекси/виртуальный адрес отличим от офиса |
| `entity.registeredAt.id` | орган регистрации: RA000752 (Meydan FZ), RA000715, RA000573, RA000569… — фактически «какая фризона» |
| `entity.registeredAs` | **номер лицензии** — доказательство в карточке лида |
| `entity.creationDate` | дата создания юрлица; сортировка `sort=-entity.creationDate` работает |
| `entity.status`, `registration.status` | активность юрлица и статус регистрации LEI |
| `registration.nextRenewalDate` | **дата продления LEI**; сортировка `-registration.nextRenewalDate` даёт свежепросроченные первыми |
| `relationships.direct-parent`, `ultimate-parent` | структура группы: материнская компания за рубежом → заход международной группы в ОАЭ |

## Два лид-движка на одном источнике

**1. Просроченный комплаенс.** Юрлицо активно, а регистрация LEI просрочена. По 400
свежайшим просрочкам: медиана просрочки 65 дней, 272 просрочены за последние 90 дней,
245 из них в Дубае; топ-регистратор — RA000752 (118). Повод датирован и доказуем:
номер LEI, номер лицензии, дата, на сколько дней просрочено.

**2. Новые компании на адресе регистратора.** Создана недавно, адрес — здание фризоны
(Meydan Grandstand и подобные) → сидит на флекси, при найме упрётся в визовую квоту.

Оба движка идут через ту же рубрику и ту же очередь, что и входящие обращения.

## Границы источника (важно и будет в README)

GLEIF содержит только компании, получившие LEI, — это не все ≈215 000 активных лицензий
Дубая, а срез, смещённый к финансовым, торговым и фондовым структурам. Плюс среза: это
более крупный и платёжеспособный сегмент, чем средняя новая лицензия. Минус: поток
новых — десятки в месяц, а не тысячи. Числа выше измерены, не оценены.

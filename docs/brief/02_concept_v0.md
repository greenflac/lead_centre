# Концепция v0: AI Lead Generation Pipeline для SORP Business Centre

> Источник: черновик концепции, переданный пользователем 2026-09-09. Это исходная гипотеза,
> НЕ согласованный ТЗ. Согласованная версия появится после вопросов — см. HANDOFF.

## Context
SORP Group — международная группа, HQ в ОАЭ, 19 лет, 500+ компаний в управлении.
Ключевой актив: SORP Business Centre (7 500 кв. м, Barsha Heights, Dubai).

**Проблема:** лиды только входящие (сайт, Google, Property Finder). Нет исходящей
автоматизированной системы поиска и квалификации арендаторов.

**Цель:** MVP AI-агента, который
1. автоматически находит потенциальных арендаторов;
2. оценивает «горячность» (скоринг);
3. генерирует персонализированные предложения;
4. передаёт лиды в отдел продаж (или отправляет автоматически).

## Business Value
| Что получает SORP | Как измеряем |
|---|---|
| Новый исходящий канал лидов | Кол-во новых лидов в неделю |
| Продажи работают только с «горячими» | Конверсия лид → показ офиса |
| Растёт заполняемость БЦ | % заполняемости |
| Кросс-продажа консалтинга (аренда + регистрация + визы) | Доп. доход с клиента |

**Главный KPI:** количество HIGH-лидов, переданных в отдел продаж.

## Architecture (conceptual)
1. DATA COLLECTION — LinkedIn, базы компаний ОАЭ, Property Finder → название, сфера, размер, возраст.
2. AI SCORING ENGINE — LLM по критериям: размер > 5, сфера (tech/finance/consulting/crypto/trading),
   недавно открылись в ОАЭ (3–6 мес), бюджет под Barsha Heights → HIGH / MEDIUM / LOW.
3. PERSONALIZATION ENGINE — LLM генерирует предложение: имя компании, адаптация под сферу,
   синергия с консалтингом (визы, счета, регистрация).
4. OUTREACH & CRM — HIGH → моментальный аутрич (email / LinkedIn); MEDIUM → CRM для будущих
   кампаний; LOW → архив (перепроверить через 3 месяца).

## Criteria for Scoring
- **HIGH:** > 5 сотрудников; активно растёт в ОАЭ; бюджет на аренду 2+ лет в Barsha Heights;
  сфера tech / finance / consulting / crypto / trading.
- **MEDIUM:** 2–5 сотрудников; ищет коворкинг или офис на 6 мес; бюджет под shared space.
- **LOW:** solo / < 2 сотрудников; бюджет не соответствует; компания не в ОАЭ.

# Документы

Начните с корневого [`../README.md`](../README.md): что это за система, как её запустить,
какие числа измерены и какой командой. Остальное читается по надобности:

- [`onepager.md`](onepager.md) — одна страница без терминов: задача, решение, что показано честно.
- [`loom_script.md`](loom_script.md) — сценарий четырёхминутной демонстрации по работающим экранам.
- [`data/inbound_seed.md`](data/inbound_seed.md) — набор из 70 обращений: состав, края диапазона, правила разметки.
- [`data/gleif_schema.md`](data/gleif_schema.md) — реестр LEI: поля, объёмы по ОАЭ, границы источника.
- [`../eval/README.md`](../eval/README.md) — что означает каждое измеренное число и где стенд слаб.

Интерфейс описан отдельно: [`../web/README.md`](../web/README.md).

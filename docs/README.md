# Указатель по документам

Репозиторий делался как проактивное тестовое задание, поэтому здесь лежит и сам продукт,
и вся работа вокруг него. Чтобы не разбирать кучу, вот что читать и в каком порядке.

## Если вы оцениваете работу

| Файл | Что это | Кому |
|---|---|---|
| [`../README.md`](../README.md) | Что это, архитектура, запуск, измеренные числа, границы данных, что не сделано | технический читатель |
| [`onepager.md`](onepager.md) | Одна страница без терминов: задача, решение, результат | нетехнический читатель |
| [`loom_script.md`](loom_script.md) | Сценарий четырёхминутного видео по работающим экранам | — |
| [`DEMO_brief.md`](DEMO_brief.md) | Короткий пересказ: что умеет, что готово, чего нет | — |

Три числа, по которым можно проверить всё остальное: `make test-ci` — 275 тестов;
`PYTHONPATH=. python3 eval/run_eval.py --labels eval/labels_synthetic.csv` — каппа и
негативные контроли; `PYTHONPATH=. python3 scripts/e2e_demo.py` — обещание из первого
абзаца README, проверенное по пунктам.

## Рабочее окружение

[`ops/`](ops) — состояние ключей и сети, проверялки вайтлиста и ключей с негативными
контролями. Нужно, чтобы повторить прогоны в другой среде.

## Что помечено как незакрытое

Отступления от собственных правил помечены в коде строкой `# DEBT(дата)` и грепаются:

    grep -rn "DEBT(" --include=*.py --include=*.ts .

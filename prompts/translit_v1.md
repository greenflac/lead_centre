# translit_v1 — латинское написание арабского названия компании (ОАЭ)

Ты переводишь в латиницу название компании из реестра ОАЭ. Это транслитерация для того,
чтобы менеджер понял, о какой компании речь, и смог её найти, — не юридический перевод.

## Правила

1. Верни **только** латинское написание названия. Ни пояснений, ни кавычек, ни вариантов
   через слэш, ни арабского текста в ответе.
2. Держись написания, принятого в реестрах ОАЭ (латиница, как в торговой лицензии):
   заглавными, слова через пробел.
3. **Организационно-правовые формы передавай принятыми сокращениями**, а не побуквенно:
   `ذ.م.م` / `ش.ذ.م.م` → `L.L.C`; `ش.ش.و` / `شركة الشخص الواحد` → `SOLE PROPRIETORSHIP`;
   `م.م.ح` → `F.Z.E`; `ش.م.ح` → `F.Z.C`; `ش.م.ع` → `P.J.S.C`; `ش.م.خ` → `P.S.C`.
4. Общие слова названия передавай их обычным английским соответствием, как это делают
   сами компании ОАЭ: `للتجارة العامة` → `GENERAL TRADING`, `للمقاولات` → `CONTRACTING`,
   `للاستثمار` → `INVESTMENT`, `للمفروشات` → `FURNITURE`, `للاستشارات` → `CONSULTING`.
   Собственное имя (марка, фамилия) — транслитерируй по звучанию.
5. Скобки и дефисы сохраняй там, где они есть в оригинале.
6. Не выдумывай слов, которых в названии нет, и не выбрасывай части названия.

## Примеры

`غاووتام للتجارة العامة (ش.ذ.م.م)` → `GAUTAM GENERAL TRADING (L.L.C)`
`دعاء بيبي - م.م.ح` → `DUA BABY - F.Z.E`
`انغما للاستثمار التجاري - شركة الشخص الواحد ذ م م` →
`ENIGMA COMMERCIAL INVESTMENT - SOLE PROPRIETORSHIP L.L.C.`

Ответ — одна строка с названием, больше ничего.
